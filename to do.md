# EVSU Screentime Tracking App - Missing Features List

## Authentication & Account Management
1. **Password Recovery System** - Implement forgot password functionality with secure email verification and reset token validation
2. **Session Management & Logout** - Enable users to securely log out with automatic session timeout after inactivity period
3. **Account Deletion** - Provide users with an option to permanently delete their account and associated screentime data

## User Profile & Social Features
4. **Student Profile Page** - Create comprehensive profile featuring student photo avatar, editable cover photo, earned badges display, and bio/about section
5. **Add Friend Functionality** - Allow users to send and manage friend requests directly from the student profile page
6. **Student Avatar Integration in Rankings** - Display student avatars across all ranking sections (EVSU, Department, Friends) with tap-to-profile navigation
7. **Search Functionality in Rankings** - Enable users to search and filter students by name or identifier across all ranking categories

## Navigation & UI Improvements
8. **Profile Navigation Restructuring** - Redirect the main Profile navigation button to Student Profile page instead of Account Settings
9. **Sidebar Panel Terminology Update** - Rename "Profile" option in sidebar to "Account Settings" or "Account" to avoid confusion with main profile
10. **Settings & Preferences Page** - Centralized settings menu to control notifications, privacy levels, reminder frequency, theme preference, and other user preferences

## Notifications & Reminders
11. **Gentle Reminder Overlay Notifications** - Display persistent notifications over active apps showing current screentime usage and encouraging healthy habits
12. **Achievement Notifications** - Send alerts when users unlock badges, reach milestones, or accomplish screentime-related goals

## Analytics & Data Visualization
13. **App Usage Breakdown Chart** - Implement pie chart or bar graph visualization showing distribution of screentime across different app categories
14. **Top Offenders List** - Display top 5-10 most-used apps with corresponding time spent data on dashboard or analytics section
15. **Multi-Device Conflict Resolution** - Implement data synchronization protocol to handle screentime tracking conflicts when users access app from multiple devices

## Engagement & Growth
16. **Referral & Rewards System** - Create incentive program that rewards students for inviting friends to join the app with badges or recognition

## Support & Documentation
17. **FAQ/Help Section** - Compile frequently asked questions and provide clear answers about app features, data privacy, and troubleshooting
18. **Support & Feedback Channel** - Implement contact form for users to report bugs, suggest features, and request technical support
19. **Terms of Service & Privacy Policy** - Draft and display legal documentation outlining user rights, data handling practices, and platform policies
